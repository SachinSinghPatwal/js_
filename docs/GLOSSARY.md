# V8 & ECMAScript Glossary

## AST (Abstract Syntax Tree)
A tree representation of JavaScript source code structure generated by the Acorn parser.

---

## Execution Context (EC)
A specification object created by V8 when executing code. Contains a Lexical Environment, Variable Environment, `this` binding address, and `outerReference`.

---

## Global Execution Context (GEC)
The baseline execution context created when code starts. Bound to the global object (`window` or `globalThis`).

---

## Function Execution Context (FEC)
A local execution context pushed onto the Call Stack when a function is invoked.

---

## Lexical Environment
A runtime component that stores variable and function bindings and maintains an `outer` link for scope chain resolution.

---

## Environment Record
The storage structure inside a Lexical Environment that holds name-value bindings.

---

## Temporal Dead Zone (TDZ)
The time span between entering a scope (where `let` and `const` bindings are allocated) and evaluating their initializer. Accessing a binding in TDZ throws a `ReferenceError`.

---

## Hoisting
V8's creation phase behavior where variable declarations (`var`, `let`, `const`) and function declarations are allocated in the Environment Record before code execution begins.

---

## Memory Heap
A region of memory used for storing reference types (Objects, Functions, Promises, Arrays, Closures) referenced by memory addresses like `0x0001`.

---

## Closure
A function object stored in Heap memory that retains a hidden `[[Environment]]` pointer to its outer lexical declaration scope.

---

## Event Loop
The mechanism in JavaScript host environments that coordinates synchronous execution, Microtask queue draining, rendering, and Macrotask dequeuing.

---

## Microtask Queue
A high-priority queue that holds `PromiseReactionJob` items. The event loop drains this queue completely before performing repaints or taking macrotasks.

---

## Macrotask Queue (Task Queue)
A queue managed by host environments holding timer callbacks (`TimerTask` from `setTimeout`) and I/O events. The event loop processes exactly 1 macrotask per tick.

---

## Mark-and-Sweep Garbage Collection
A V8 memory management algorithm that identifies unreachable objects from root references (Execution Contexts & Global Object) and frees their memory heap allocation.
