# Glossary

## AST

Abstract Syntax Tree.

---

## Scope

A lexical region that owns declarations.

---

## Binding

A named entry inside a scope.

---

## Scope Tree

The hierarchy of lexical scopes.

---

## Execution Context

The runtime structure created when code executes.

---

## Lexical Environment

The runtime object used to resolve identifiers.

---

## Environment Record

Stores bindings inside a lexical environment.

---

## Hoisting

Creation of bindings before execution.

---

## TDZ

Temporal Dead Zone.

The period where a let or const binding exists but cannot yet be accessed.

---

## Closure

A function together with its captured lexical environment.
